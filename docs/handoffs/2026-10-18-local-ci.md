# Pivot Handoff — Local CI

Date: 2026-10-18
Branch / commit: uncommitted
Status: Complete

## Objective

Set up local CI before daemon/client integration.

## Implemented

- `scripts/ci.py`: one-command, sequential local pipeline, streamed and saved logs,
  nonzero failure exit, tool preflight, and timestamped JSON summaries.
- Rust formatting, locked Clippy/tests, .NET Release build with warnings as errors,
  and the complete cross-language decimal suite.
- Compatibility script supports configurable output directory/configuration and
  prints subprocess diagnostics on failure. CI does not overwrite reference reports.
- README usage, setup documentation, and Python cache ignore rules.

## Interface / semantics

Run `python scripts/ci.py`. Artifacts go under ignored `artifacts/ci/<run>/`.
The runner stops on the first failure and logs only executed gates. Tool versions
and actual commands are recorded. No CI server, hooks, scheduling, or deployment
was introduced. No new dependencies were added.

## Tests actually run

- `python scripts/ci.py` — PASS outside sandbox: all 22 Rust tests, strict Clippy,
  formatting, .NET Release build with zero warnings/errors, and 10,099 parity vectors
  with zero value/error or scale differences.
- Intentional child process exit 7 — PASS: runner retains exit code and log output.
- Initial sandboxed pipeline — correctly FAILED at the .NET cache-access boundary;
  approved rerun completed successfully.

## Decisions made or proposed

- **Implementation choice:** repository-owned Python runner, suitable for manual
  use now and later reuse by a CI service. No external infrastructure selected.

## Open issues / risks

Rust toolchain and NuGet lockfiles are not pinned. Only Windows has been exercised.
Native AOT and GUI execution are not checked. Artifacts have no retention policy.
Local CI currently requires an explicit command; automatic triggers remain future
work if requested.
