## Interface / semantics

Frames contain one Protobuf payload each; lengths outside 1..=1 MiB are rejected
before payload allocation. Reads/writes have five-second deadlines, including idle
reads. Each connection handshakes once and supports sequential operations. Malformed
traffic terminates only its connection or receives a bounded public protocol error.
The daemon reuses pivot-host validation and invocation; the CLI never evaluates.

The demo uses external model `restaurant-profit`, revision `demo-v1`, required
Revenue, Costs defaulting to 85000, and outputs Net/Margin. CLI discovers a unique
revision or requires `--revision`. Missing --outputs selects all public outputs.
Exit codes: 0 success, 1 request/connection/argument failure, 2 calculation error.

Graceful shutdown stops accepting, cancels and joins connections, and releases the
endpoint. It does not guarantee delivery of in-flight responses. --shutdown-stdin
is opt-in supervisor/test control, not a protocol operation. No results are stored.

## Open issues / risks

Windows runtime is verified. Linux/macOS source has not been compiled or executed
here; only Windows/UEFI Rust targets are installed. Actual access denial under a
different user was not tested. ACL inspection is useful evidence, not that test.
Same-user malicious service impersonation and administrator/root bypass remain;
this is OS-user identity, not application identity. Privileged/protected peer token
inspection can fail closed. No insecure fallback exists.

The work budget is conservative and rejects some large graphs even for small output
selections. It is not a wall-clock limit or full quota scheduler. Idle peers time out
after five seconds. Synchronous bounded work may complete before shutdown cancellation.
Unix forced crashes can leave stale sockets requiring explicit cleanup; normal cleanup
never deletes unrelated/replaced paths. Native AOT and fuzzing remain unverified.

No TCP listener, shared memory, persistence, global mutable calculation cache, GUI,
retained-result service, automatic publication, general scripting, full REPL, or
editable document-management layer was added.
